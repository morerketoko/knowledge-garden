# Knowledge Garden（知识花园）

> 一个把 Obsidian 变成「会自己发现、帮你复盘、陪你长期演化」的个人知识系统。
> **它不是「AI 自动总结机器人」，而是「AI 知识连接器」。**

[简体中文](./README.md) | [English](./README_EN.md)

---

## 这个插件是做什么的？

很多 AI 插件只会帮你「自动摘要、自动标签、自动写进笔记」。结果你的库越来越大，但你自己越来越不知道自己有什么。

Knowledge Garden 的做法不同。它把知识的**发现 → 确认 → 连接 → 复盘 → 再探索**做成一个完整闭环，并且坚持三条原则：

1. **AI 建议 ≠ 知识**。AI 只负责「发现值得注意的连接和线索」，**确认和沉淀永远由你完成**。
2. **本地计算在前，AI 在后**。知识索引、状态判定、候选筛选、复盘队列都是本地计算，**只有需要判断「值得连接吗」时才调用 AI**。
3. **「整个仓库」是搜索范围，不是上传量**。AI 只会收到筛选后的候选内容，**不会把你的整个笔记库上传**。

## 开始之前你需要准备什么？

| 需要的东西 | 说明 |
| --- | --- |
| Obsidian 桌面版 | 版本 ≥ 1.4.0（Windows / macOS / Linux），本插件仅支持桌面端 |
| 一个笔记库（Vault） | 你日常使用的 Obsidian 仓库 |
| SiliconFlow 账号（可选但推荐） | 提供 AI 能力的服务商，注册即可，新用户通常有免费额度 |

> 💡 没有 AI Key 也能用：Dashboard、知识索引、复习队列、知识演化快照等大部分功能都是**本地计算（0 AI）**，不调 AI 也能正常使用。

## 一、安装插件（最简单的方式）

插件已经构建好（内含 `main.js`），**不需要编译**，复制文件夹即可使用：

1. 找到插件文件夹：`E:\ob仓库\.obsidian\plugins\knowledge-garden`
2. 把整个 `knowledge-garden` 文件夹**复制**到你的 Vault 的 `.obsidian\plugins\` 目录下（如果没有 `plugins` 文件夹就自己新建一个）
3. 打开 Obsidian → 设置 → 第三方插件 → 若提示「受限模式」请先**开启**第三方插件 → 在已安装插件列表中找到并**启用**「Knowledge Garden (知识花园)」
4. 按 `Ctrl+P` 打开命令面板，输入并运行：**「打开知识花园 Dashboard」**

看到「知识花园 Dashboard」页面，就说明安装成功了。

> 🛠 如果你是开发者、想从源码自己构建，请看文末「开发者：从源码构建」。

## 二、第一次使用（5 步上手）

1. **打开 Dashboard**：`Ctrl+P` → 「打开知识花园 Dashboard」，它会自动初始化 `Knowledge Garden/` 目录结构。
2. **配置 AI**（可选但推荐）：Obsidian 设置 → Knowledge Garden → AI，填写 Base URL、模型名称、API Key（详见下文「配置 AI」）。
3. **测试连接**：运行命令「测试 AI 连接」，出现成功提示就代表 AI 配置可用。
4. **生成今日知识奇想**：运行命令「生成今日知识奇想」，AI 会从你的知识库里找出今天值得关注的连接与线索。
5. **提问探索**：运行命令「打开 Query Explorer」，输入一个问题或关键词，系统会从全库检索并生成一条可阅读的知识关联链路。

## 三、配置 AI（最关键的设置）

### 3.1 获取 SiliconFlow API Key（5 分钟）

1. 打开 https://siliconflow.cn，注册并登录
2. 进入控制台 → 左侧「API 密钥」→ 新建密钥
3. 复制生成的密钥（形如 `sk-xxxxxxxx...`），**只保存在你自己的电脑上**

> ⚠️ **安全提示**：API Key 只会保存到本地 `data.json` 文件中，**不会**被写进源码、不会上传到 GitHub，也请不要把 Key 发给任何人。如果怀疑泄露，请到 SiliconFlow 控制台撤销旧 Key 并重新生成。

### 3.2 在插件里填写

打开 Obsidian 设置 → Knowledge Garden → **AI**：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| Base URL | `https://api.siliconflow.cn/v1` | SiliconFlow 服务地址，一般不用改 |
| Model（模型） | `Qwen/Qwen2.5-7B-Instruct` | SiliconFlow 上可用的模型名，可按需更换 |
| API Key | 空 | 粘贴你刚才复制的密钥 |
| Temperature | `0.7` | 生成随机性，0=严谨机械，1=天马行空 |
| Max Tokens | `1500` | 单次回复最大长度 |
| Timeout（超时） | `60` 秒 | 等待 AI 回复的最长时间 |

填完后运行命令 **「测试 AI 连接」**，成功即配置完成。

### 3.3 省钱与省额度技巧

- 大多数统计、队列、快照都是**本地计算，0 AI**，不消耗任何 Token
- **自动复盘默认关闭**，确认后才会按周期运行（首次安装不会默默消耗）
- 插件带 **AI 缓存**：同一请求重复执行会直接命中缓存，**0 AI 请求**
- 随手打开一篇笔记**不会**让缓存全部失效——只有真正影响结果的因素变化才会重新生成

## 五、核心功能使用说明书

### 5.1 今日知识奇想（AI 发问）
AI 从你的知识库里筛选出「值得注意的新连接、长期未解决问题、跨领域关联」等线索，生成今天的奇想。
- 命令：「生成今日知识奇想」（加「强制」前缀的命令可跳过缓存重新生成）

### 5.2 今日知识漫游连接（AI 连接知识）
AI 把几篇笔记连成一条**有解释的路径**——「为什么这几篇值得放一起」。
- 命令：「生成今日知识漫游连接（可探索知识图）」

### 5.3 Query Explorer（你发问）
输入问题或关键词 → 本地全库检索 → 候选排序 → AI 关系推理 → 生成一条可阅读的知识链路。
- 命令：「打开 Query Explorer」

### 5.4 知识图（有解释的探索路径）
它不是普通 Graph View 那种「几十个圆球蜘蛛网」，而是**一个问题 → 几篇笔记 → 几个明确关系 → 一条可阅读路径 → 点击回到笔记**。每个连接都带着 AI 当时的解释。

### 5.5 复盘与 Review Center
- 生成日 / 周 / 月 / 季度复盘：AI 帮你总结一段时间里知识的变化
- Review Center：打开「今日复习窗口」，完成今天的复习队列；勾选后命令「标记当前笔记为已复习」可手动记录
- 自动调度：设置里开启后，到时间它会提醒你该复盘了（**默认关闭**）

### 5.6 知识演化（观察长期变化）
每周生成一次**本地确定性快照**（0 AI），月度 / 季度演化会调用 AI 观察：知识在变多还是变少、有没有产生跨领域连接、哪些问题一直没解决。

### 5.7 捕获 → 提炼 → 确认（上游知识入口）
把看到的文章、网页、想法先**捕获**进来（手动 / 剪贴板 / URL），进入 Inbox → AI 初步提炼成「知识候选」→ **你确认后**才成为正式知识。
> 关键设计：**AI Candidate → Human Confirmation → Knowledge**。防止你的库变成「AI 摘要垃圾场」。

### 5.8 已确认知识关系（长期保留）
当 AI 说「A 和 B 可能有关」时，你觉得确实有意思，就可以**确认**。确认后的关系会以 **Markdown 文件落盘**（`Relationships/` 目录），即使清空 AI 缓存、重装插件，关系依然能从 Vault 恢复。

### 5.9 收藏知识链路（保存 AI 探索路径）
在知识图 / Query Explorer 里看到值得留存的路径，可以**收藏**。收藏的不是标题或缓存，而是**完整节点 + 边 + AI 当时的解释**——这就是「你曾经如何理解自己的知识」。

### 5.10 状态浏览（谁在被遗忘）
系统本地判定每篇笔记的五种状态：**新 / 增长 / 活跃 / 停滞 / 可能遗忘**。可以随机浏览某个状态的笔记，也可以运行「查看可能正在被遗忘的知识」。

### 5.11 右键 AI 工具箱（在任何笔记上使用）
在任意笔记上右键，会多出 7 个专属菜单项：

| 菜单项 | 作用 |
| --- | --- |
| ✦ 提炼到知识库 | 把当前内容提炼成知识候选，确认后沉淀 |
| 🔗 以此笔记探索关联 | 以这篇笔记为中心，探索它能和什么连接 |
| 💡 从这篇知识想想还能怎么用 | 生成应用思路 |
| ❓ 从这篇知识提出更好的问题 | 生成值得追问的研究问题 |
| ✎ AI 写作助手 | 学术 / 论证 / 批判 / 头脑风暴等写作辅助 |
| 🌐 翻译 | 把内容翻译成目标语言 |
| ✓ 标记为已复习 | 就地记录复习状态 |

### 5.12 Hero 壁纸与音乐播放器（个性化）
- **Hero**：Dashboard 顶部的大图背景（单图或随机文件夹壁纸、遮罩、标题副标题）
- **音乐播放器**：播放你本地音频文件夹（随机 / 循环 / 音量），**默认关闭，你启用后才显示**
- 这两项只是视觉与氛围，不影响核心功能

### 5.13 Knowledge Workspace / Skills（高级用户）
- **Workspace**：为不同使用场景（如「研究」「写作」）绑定不同的 AI Profile、知识区域倾向、技能列表与权限；默认不启用，保持现有行为
- **Skills**：按技能给 AI 更专业的指令上下文（如「代码审查」「学术写作」）

## 七、数据存在哪里？（放心使用说明）

| 内容 | 位置 | 说明 |
| --- | --- | --- |
| 你的知识 | 你的 Vault（Markdown） | **Markdown 是唯一知识源**，插件不改变你的笔记 |
| 捕获 / 候选 / 已确认知识 | `Knowledge Garden/`（Inbox / Processing / Knowledge / Archive） | 都是 Markdown 文件 |
| 已确认知识关系 | `Relationships/` | Markdown 落盘，可随 Vault 恢复 |
| 收藏链路 | `Saved/` | Markdown 落盘 |
| AI 缓存与程序状态 | 插件目录 `cache/` 等 | 可随时清空，不影响你的知识 |
| 设置与 AI Key | 插件目录 `data.json` | **仅本地**，`.gitignore` 已排除，不会上传 |

**自愈机制**：损坏的缓存会被自动隔离（不会让插件崩溃）；诊断面板提供重建索引 / 重建搜索索引 / 重建复习队列 / 清理过期缓存等修复操作。

## 八、常见问题（FAQ）

**Q：AI 没反应 / 转圈很久？**
先运行「测试 AI 连接」。若失败，检查：Base URL 是否填对、API Key 是否完整正确、模型名是否存在、网络是否可访问 SiliconFlow。

**Q：会把我的整个笔记库上传给 AI 吗？**
不会。AI 只收到「本地候选筛选」之后的内容（默认每类 16 个候选左右），全库只是搜索空间。

**Q：清空 AI 缓存会丢我的收藏或已确认关系吗？**
不会。收藏（Saved/）和已确认关系（Relationships/）都是 Markdown 文件，独立于 AI 缓存。

**Q：我只是随手打开了几篇笔记，AI 缓存会全部失效吗？**
不会。「最近访问」是独立的活动记录，不影响缓存有效性（项目明确设计：打开笔记 ≠ 缓存失效）。

**Q：自动复盘会偷偷消耗我的额度吗？**
默认关闭，且确认后才会运行；同时有 AI 缓存兜底。

**Q：装了插件后我的笔记会被改动吗？**
只有你主动执行「提炼为知识」「确认关系」「捕获」等写入类操作时才会新建/修改文件；日常浏览、生成缓存都不改你的笔记原文。

## 九、开发者：从源码构建

```bash
cd knowledge-garden
npm install
npm run build   # 产出 main.js
```

构建产物 `main.js` + `manifest.json` + `styles.css` 就是可直接放入 `Vault/.obsidian/plugins/` 的插件本体。若构建报错，把 `node_modules` 删除后重新 `npm install` 再试。

> 📁 本仓库的 `.gitignore` 已排除 `data.json`（含本地 API Key）、`node_modules` 与 `cache/`，推送 / 克隆到 GitHub 不会包含任何密钥。
